# My Marvin — Continuous Integration with Jenkins

[![Epitech: Tek2](https://img.shields.io/badge/Epitech-Tek2-005696.svg)](https://www.epitech.eu/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)


A DevOps project that sets up a **Continuous Integration pipeline with Jenkins** to
automatically enforce code quality on every contribution — no human intervention needed.

Built as part of the Epitech curriculum (DOP-400 module).

## ✨ Features

- 🤖 Jenkins pipelines defined **as code** (Job DSL, Groovy)
- 🐳 Containerized build environments with Docker for full reproducibility
- ✅ Automatic coding-style checks on every push
- 🔁 End-to-end continuous integration workflow

## 📂 Contents

- `job_dsl.groovy` — Jenkins jobs defined declaratively (Job DSL)
- `my_marvin.yml` — pipeline / job configuration
- `bonus/` — additional Docker setup and coding-style tooling

## 🛠️ Tech stack

Jenkins · Job DSL (Groovy) · Docker

## 🧠 What I learned

Automating quality control so that every commit is verified automatically — shipping
faster and with more confidence. Exactly the DevOps mindset I love.
